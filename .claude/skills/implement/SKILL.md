# Імплементація схваленої фічі

Працюєш **тільки** за схваленою специфікацією. Номер тікета в `$ISSUE`.

## Крок 0. Перевір мандат

Обовʼязково має бути лейбл `spec:approved`, поставлений **людиною**.
Перевір, хто його поставив:

```bash
gh issue view $ISSUE --json timelineItems -q '.' 2>/dev/null || gh issue view $ISSUE --comments
```

Немає `spec:approved` — зупинись, нічого не роби, напиши чому. Не апрувай сам.

Постав `ai:in-progress`, зніми наприкінці.

## Крок 1. Перечитай специфікацію

Знайди останній коментар зі специфікацією і **всі** зауваження людини після нього.
Якщо людина щось уточнила в коментарях після специфікації — це частина завдання.

Специфікація — межа роботи. Усе, що в «Поза межами», не робиться, навіть якщо руки сверблять.

## Крок 2. Спочатку тести

На кожен пункт «Критеріїв приймання» — окремий Playwright-тест у `tests/`.
Запусти їх до реалізації: вони мають падати. Так ти знаєш, що вони справді щось перевіряють.

## Крок 3. Реалізуй

Гілка `ai/$ISSUE-<короткий-опис>` від свіжого `main`.

Тримайся конвенцій із `CLAUDE.md`: ванільний JS, CSS-змінні, адаптив від 360px,
`prefers-reduced-motion`, українська в інтерфейсі, коментарі українською.
Нових залежностей не додавай.

Якщо під час роботи зʼясувалося, що специфікація неможлива або помилкова — **зупинись**,
постав `needs-human`, поясни в коментарі що саме не сходиться. Не переписуй завдання на ходу.

## Крок 4. Доведи

```bash
npm test                                    # уся сюїта
node scripts/evidence.mjs feature-$ISSUE
node scripts/evidence.mjs feature-$ISSUE --mobile
```

Скріншоти комітяться в гілку. Для фічі потрібен десктоп **і** мобільний вигляд.

## Крок 5. PR

```markdown
Fixes #$ISSUE

## Що зроблено
Коротко, за специфікацією з #$ISSUE.

## Критерії приймання
| Критерій | Тест | Статус |
|---|---|---|
| Після кліку на «Поділитися» відкривається системне вікно | `tests/share.spec.js:12` | ✅ |

## Докази
| Десктоп | Мобільний |
|---|---|
| ![десктоп](https://raw.githubusercontent.com/vidprog/-coffee-ground-tests/<гілка>/docs/evidence/feature-$ISSUE-result.png) | ![мобільний](https://raw.githubusercontent.com/vidprog/-coffee-ground-tests/<гілка>/docs/evidence/feature-$ISSUE-result-mobile.png) |

Уся сюїта: N passed.

## Поза межами
Перелічи, що свідомо не робив (зі специфікації).

<sub>🤖 Автоматична імплементація · мердж робить людина</sub>
```

Draft → `gh pr ready` коли зелено. Коментар у тікет із посиланням, зняти `ai:in-progress`.

## Заборонено

Починати без `spec:approved`, виходити за межі специфікації, мерджити,
пушити в `main`, міняти `.github/` і `.claude/`.
